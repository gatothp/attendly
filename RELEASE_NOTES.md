# 📋 Attendly — Release Notes

---

## 🆕 v1.2

### 🇮🇩 Indonesia

Pembaruan ini menghadirkan peningkatan pada fitur pemindaian dan penomoran scan.

**Yang baru:**

- 📷 **Bingkai kotak** — kamera kini menampilkan bingkai berbentuk kotak saat memindai kode QR.
- 🖼️ **Scan dari galeri** — tahan tombol Scan untuk memilih gambar dari penyimpanan perangkat yang berisi kode QR.
- 🔢 **Penomoran scan otomatis** — setiap scan diberi nomor urut (Scan #1, Scan #2, dst.) yang ditampilkan di halaman utama.
- ⚙️ **Reset nomor scan** — tombol baru di Pengaturan → Nomor Scan untuk mereset hitungan kembali ke 0.
- 🛠️ Peringatan build Gradle diselesaikan (kompatibel dengan Gradle 10).

---

### 🇬🇧 English

This update brings improvements to the scanning experience and introduces scan numbering.

**What's new:**

- 📷 **Square viewfinder** — the camera now shows a square framing box when scanning QR codes.
- 🖼️ **Scan from gallery** — long-press the Scan button to pick an image containing a QR code from device storage.
- 🔢 **Automatic scan numbering** — every scan is labelled Scan #1, Scan #2… and shown on the main screen.
- ⚙️ **Reset scan number** — new button in Settings → Scan Number to reset the counter back to 0.
- 🛠️ Gradle deprecation warnings resolved (Gradle 10 compatibility).

## v1.1.0

### 🇮🇩 Indonesia

Terima kasih telah menggunakan Attendly! Pembaruan ini membawa sejumlah peningkatan penting.

**Yang baru:**

- 🌐 **Dukungan dua bahasa** — Aplikasi kini tersedia dalam Bahasa Indonesia (default) dan English. Ganti bahasa kapan saja melalui menu Pengaturan → Bahasa.
- 🔗 **Tautan bantuan di Pengaturan** — Teks "Lihat bantuan" di bagian Sheet langsung membuka panduan konfigurasi Google.
- 🔗 **URL dapat diklik di Bantuan** — Tautan skrip di Langkah 3 kini dapat langsung diklik untuk membuka browser.
- ✅ **Teks antarmuka sepenuhnya dilokalisasi** — Semua teks dalam aplikasi kini mengikuti bahasa yang dipilih.
- ℹ️ **Versi aplikasi ditampilkan di Info** — Halaman Info kini menampilkan versi terkini secara otomatis.

**Perbaikan teknis:**
- Performa lebih baik pada build rilis
- Keamanan data lokal ditingkatkan

---

### 🇬🇧 English

Thank you for using Attendly! This update brings several important improvements.

**What's new:**

- 🌐 **Bilingual support** — The app is now available in Indonesian (default) and English. Switch languages anytime via Settings → Language.
- 🔗 **Help link in Settings** — The "See help" text in the Sheet section opens the Google configuration guide directly.
- 🔗 **Clickable URL in Help** — The script link in Step 3 can now be tapped to open directly in the browser.
- ✅ **Fully localized UI** — All on-screen text now follows the selected language.
- ℹ️ **App version shown in Info** — The Info screen now displays the current version automatically.

**Technical improvements:**
- Better performance on release builds
- Improved local data security
